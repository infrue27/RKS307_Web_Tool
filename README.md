# 🍒 Petit Pix

Alat foto sederhana untuk mengubah ukuran (pasfoto 2×3, 3×4, 4×6, kustom), mengonversi format (JPG / PNG / WebP), dan mengompres foto. Semua diproses langsung di browser, foto tidak diunggah ke server.

## Fitur
- Ubah ukuran cetak 300 dpi, dengan geser foto untuk mengatur bagian yang dipotong
- Konversi JPG, PNG, dan WebP
- Kompres dengan pengaturan kualitas
- Nyaman dipakai di HP

## Cara pakai
Buka `index.html` di browser, atau aktifkan GitHub Pages (Settings → Pages → branch `main`, folder `/root`).

> Label endpoint di header masih tampilan prototype, belum terhubung ke backend.
